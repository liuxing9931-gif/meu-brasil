# Fala · Chrome 随身复习（预览版 0.1）

这是独立的 Chrome Manifest V3 侧栏扩展。原 Fala 页面、课程、阅读、已存学习数据均未修改。本分支只提供预览与可选安装包，不会替用户安装或开启真实网站同步。

## 先预览，不需要安装

下载已打包的 `fala-sidepanel-preview.zip`，解压后双击 **preview.html**。右侧界面可以切换全部/单词/短语/句子、查看答案、四档评分、查词及查看动词变位。背景工作页面为静态示意，不读取工作内容。也可直接打开 `sidepanel.html` 看窄侧栏。

浏览器模式始终标记“预览模式”，使用内存中的示例收藏。它不连接真实 Fala，不读写 Chrome 插件存储、不导入或导出真实学习数据，刷新后示例重置。预览不是安装，也不能证明真实设备语音包存在。

## 可选安装（决定安装后再做）

1. 在 Fala 的学习设置中先导出 JSON 学习备份。
2. 解压插件包，确认文件夹内直接有 `manifest.json`、`sidepanel.html`、`background.js`、`shared/` 等。
3. Chrome 地址栏打开 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择上一步文件夹。需要 Chrome 116 或更新版本；其他 Chromium 浏览器是否支持 Side Panel API 需另行确认。
4. 在浏览器扩展菜单中将 Fala 固定到工具栏。点击图标打开侧栏，使用 Chrome 侧栏右上角的原生 × 随时关闭。
5. 默认静音。设置中可选择“显示答案后自动朗读”、语速和设备的巴葡声音。没有 pt-BR 语音时会提示，可安装系统语音包后使用。关闭侧栏、隐藏页面或评分时会停止旧声音。

不需要将本分支合并到 GitHub Pages，也不需要 API Key、AI 服务或服务器。卸载插件会清除它的本地数据；尚未同步的评分请先导出保留。

## 导入与同步

- 侧栏初次为空，点击“从 Fala 同步”，或在设置里导入原有 **Fala v1 JSON** 备份。
- 自动同步仅支持 `https://liuxing9931-gif.github.io/meu-brasil/`，且必须在 **同一个 Chrome 用户配置** 中。Edge、另一个 Chrome 用户配置、另一台电脑的数据不会自动出现，需要导出/导入备份；不存在通用的“Chrome 单词数据库”。自定义域名、本地地址和其他项目暂不支持自动同步。
- 你点击同步时，扩展会使用已有 Fala 页面；没有时会打开一个后台 Fala 标签页。需要联网打开网站，或该网站在当前 Chrome 已有可用离线缓存。该标签页不会自动关闭；完成后你可以关闭它，侧栏使用自己的本地快照，不依赖网站常开。
- 同步通过 `chrome.scripting` 在**指定 Fala 页面**中访问当前已加载的 `state`，读取的持久化键只有 `fala-v1`。不会读取其他站点，也不读取 API 密钥、浏览历史或工作页面。
- 为避免多个 Fala 页面的内存状态互相覆盖，同步时只保留一个 Fala 网站/PWA 窗口。检测到多个匹配页会停止同步并提示。不要同时在多个 Fala 窗口评分；跨标签页并发写入不是原网站已有存储模型能完全保证的能力。
- 侧栏离线评分立即写入 `chrome.storage.local`，使用原 `core.js` 的间隔复习算法及每日上限。下次手动同步时合并到 Fala，再拉取最新收藏。侧栏可添加查到的生词；第一版不支持删除收藏或修改已有收藏释义。
- 同步保留网站的课程、打卡、完整设置、学习时段和其他字段，只更新相关卡片进度和每日新卡/复习卡/评分次数。**侧栏不累计网站学习分钟数**。
- 每个评分带独立事件 ID。重复同步不会重复计分；如果网站也改过同一张卡，或已经删除它，该卡不会被强行覆盖/恢复。冲突记录仍保留在侧栏，设置中可先导出备份，再明确选择“以 Fala 为准，放弃冲突评分”。在冲突处理前，相关卡暂停在侧栏复习。
- 侧栏备份包含待同步事件，应通过侧栏设置恢复；它不是 Fala 完整备份的替代。导入会替换侧栏快照，不更改网站；有未同步记录时禁止直接覆盖导入。正常同步不会整份覆盖网站。

在不同设备/软件窗口中不能跨浏览器读取私人存储；此版本没有云账户、后台自动同步、定时通知或在公司限制下绕过扩展安装的功能。

## 权限与许可

仅请求 `sidePanel`、`storage`、`scripting`，以及上述 GitHub Pages 主机权限。Chrome 的主机授权粒度覆盖该主机，代码进一步限制 `/meu-brasil/` 路径。没有 `<all_urls>`、`history`、`cookies`、`downloads` 权限，也没有远程执行代码、分析统计或第三方接口。所有脚本和词库随包提供，MV3 CSP 不允许远程脚本。

复用的词典、变位数据和完整许可及来源快照均在 `shared/dictionary/`；它们的离线重建脚本在 `shared/tools/`。保留这些文件再分发，见其中的 NOTICE、VERBS-NOTICE 和 licenses。

## 从源码构建与验证

在仓库根目录运行（Python 3 标准库，无需 npm）：

```bash
python3 tools/build_extension.py --out /tmp/fala-sidepanel-preview --zip /tmp/fala-sidepanel-preview.zip
python3 -m unittest discover -s tests -p 'test_extension*.py' -v
```

源码在 `extension/`，构建时将原项目的复习算法与词库复制到包内 `shared/`，不用维护两份源数据。预览与已安装插件使用同一套 HTML/CSS/评分逻辑，区别是存储与同步适配器；示例数据不会自动写进插件或网站。

本次开发环境的 Chromium 管理策略 `ExtensionInstallBlocklist=*` 禁止加载自定义扩展，未绕过策略；因此原生 MV3 侧栏的安装与容器加载尚未验证。预览通过本地 HTTP 在真实浏览器运行，后台消息用隔离 API 模拟器测试，页面桥接另在实际 Fala 页面代码上测试，不使用用户真实账户或 PWA 数据、不向线上网站写数据。原生测试默认跳过，可在允许安装扩展的测试机器设置 `FALA_TEST_NATIVE_EXTENSION=1` 后运行，始终使用临时浏览器配置。本环境还禁止 `file://` 导航，因此双击本地 HTML 的使用路径未实测；允许本地文件的机器可设置 `FALA_TEST_FILE_PREVIEW=1` 验证。预览页的 HTML/CSS/JS/词库均为本地文件，无远程脚本或 fetch 依赖。若你的工作电脑也限制本地文件或扩展安装，请先看截图，不需要调整安全设置。截图为实际运行的示例界面；朗读控制用替身检查，不代表已听测所有设备的真实发音。
