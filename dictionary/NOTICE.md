# Offline dictionary sources and limitations

Bundled dictionary snapshots retrieved on 2026-10-28. No runtime network requests or API fees are needed for these lookups.

- **FreeDict Portuguese-English (por-eng 0.2)**: 10,661 original TEI headword entries (case-folding/duplicate merging can reduce distinct lookup keys). Copyright (C) 1999–2017 various authors named in the original TEI header. Source: https://github.com/freedict/fd-dictionaries/blob/master/por-eng/por-eng.tei ; downloaded from https://raw.githubusercontent.com/freedict/fd-dictionaries/master/por-eng/por-eng.tei . License: **GPL-2.0-or-later**, full text in `licenses/GPL-2.0.txt`. The complete original TEI, including its author/revision notices, is supplied in `sources/por-eng.tei.gz`.
- **ECDICT English-Chinese**, Copyright (c) 2025 Linwei, **MIT License**, full notice in `licenses/ECDICT-MIT.txt`. Source: https://github.com/skywind3000/ECDICT ; https://raw.githubusercontent.com/skywind3000/ECDICT/master/ecdict.csv . Only rows matching up to the first five English glosses for each Portuguese entry are extracted, without modifying their translation fields; these source rows are supplied in `sources/ecdict-subset.csv.gz`. Original full-download SHA-256 digests are recorded in `sources/checksums.json`.
- `../dictionary.js` is a mechanically generated, case-folded/indexed version of the FreeDict data with English glosses (up to eight) and up to two English→Chinese pivot references. `../tools/build_dictionary.py` is the complete transformation script. Run `python3 tools/build_dictionary.py` to reproduce it entirely offline. The English→Chinese references are **not** direct Portuguese→Chinese translations and can include irrelevant senses; the UI explicitly labels these and retains the original English for comparison. This is not a context-sensitive translator or a specifically Brazilian dictionary.
- Existing lesson dictionary entries and the original reading vocabulary in `../reading-vocabulary.js` are preferred over pivot references. Handwritten aliases handle common inflections; fallback singular candidates are labeled as possible lemmas. We do not claim every word or every conjugation is covered. Unknown words retain one-click Google/optional AI lookup, without needing to copy text manually.

Keep this notice, both licenses, the supplied source snapshots and build script when redistributing the dictionary. The dictionary data's GPL notice applies to that dataset; ECDICT's MIT notice applies to the extracted English-Chinese data. These datasets are stored separately from application logic.
